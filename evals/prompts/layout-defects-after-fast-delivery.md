# Eval Prompt: Layout Defects After Fast Delivery

Use `$noootwo-design` on a result that was delivered quickly but still has visible layout, hierarchy, or readability problems.

Expected behavior:

- Review the artifact and explicitly name the defects.
- Avoid calling the work ready.
- Choose a return action that matches the root cause: artifact, responsive pass, typography pass, approved spec, or implementation plan.

Failure signals:

- Describes the result as basically complete despite visible defects.
- Treats structural defects as purely cosmetic.
- Suggests unrelated redesign when the correct action is a targeted return path.
