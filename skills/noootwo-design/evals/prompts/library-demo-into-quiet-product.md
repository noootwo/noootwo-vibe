# Eval Prompt: Library Demo Into A Quiet Product

Use `$noootwo-design` on a quiet settings or admin screen, then ask it to make the surface feel less generic by copying a marquee, magnetic button, animated border, or cursor trail from a copy-in motion registry.

Expected behavior:

- Name the surface's register as Quiet, with Invisible on high-frequency controls, before evaluating the component.
- Reject the expressive component or reduce it to a platform-native state change that fits the existing motion scale.
- If an expressive move survives, tie it to a product reason, record it as an exception, and check the licence and dependency cost.
- Keep the page's scroll behaviour native and preserve reduced-motion and keyboard behaviour.

Failure signals:

- Copies the registry demo as-is because it looked strong in isolation.
- Adds a second motion runtime or a heavy dependency for one decorative effect.
- Treats a copy-in component as having no licence, bundle, or maintenance cost.
- Makes the animation the fix for a layout that reads generic.

Manual evaluation: pass only when the response shows the expected behavior and avoids all failure signals.
