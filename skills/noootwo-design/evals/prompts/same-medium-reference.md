# Eval: Borrow a mechanism across media without pretending it is same-medium proof

Prompt: "Use an exhibition catalog's pacing as a reference for this mobile reading screen. Keep the product controls familiar."

Expected:

- Records the catalog as low or mixed same-medium fit.
- Opens and inspects the reference artifact.
- States the observed pacing mechanism actually borrowed.
- Translates that mechanism into mobile reading behavior while leaving unrelated catalog styling behind.

Fails when: it treats the print or web catalog as direct proof for mobile product UI; it copies surface styling; or it records a source without opening it.
