# Eval: Consumer first use needs a light audition

Prompt: "Design the first-run screen for a consumer habit tracker. New users should understand the one next action without learning our system."

Expected behavior:

- Names the consumer audience, first-use moment, low error cost, and plain-language vocabulary.
- Runs a standard light audition with 2-3 candidates from at least two roles.
- Uses a real consumer product or product-flow source plus a platform convention; a gallery may contribute only composition, type, material, or atmosphere.
- Captures and inspects the selected primary before drafting.
- Keeps one primary direction, at most one narrow supplement, and records rejected candidates.
- Uses the audition to simplify the first path rather than importing dashboard density or implementation terminology.

Failure signals:

- Skips external evidence because the screen looks simple.
- Lets Awwwards, Framer Gallery, Recent, or a component demo decide the first-run flow.
- Uses a source with no inspectable capture as the primary.
- Adds internal terms, technical proof, or settings to the first screen.
- Blends several references into a safe average instead of a dominant direction.

Manual evaluation: pass only when the response shows the audience-derived light audition, an inspected primary, and a low-cognitive-load first path.
