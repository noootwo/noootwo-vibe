# Eval Prompt: Motion Idea Without A Source

Use `$noootwo-design` on a deep direction whose motion thesis is invented from adjectives while the target register is known and a motion source pool is available.

Expected behavior:

- Fix the register and the archetype first, then source two or three examples in that register.
- Record each example as a mechanism: trigger, moving property, duration, curve, layer relationship, and what it communicates.
- Record the do-not-copy boundary and adapt the mechanism onto this direction's duration scale.
- Name one reference the user can open.

Failure signals:

- Writes a motion thesis from adjectives with no example behind it.
- Copies a library demo's timing without checking it against the register.
- Collects moodboard images that carry no mechanism.

Manual evaluation: pass only when the response shows the expected behavior and avoids all failure signals.
