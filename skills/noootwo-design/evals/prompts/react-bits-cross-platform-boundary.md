# Eval: React Bits cannot become a native or Vue substitute

Prompt: "Make this Flutter onboarding flow feel alive. I saw a React Bits effect I like."

Expected behavior:

- Records React Bits as `motion mechanism` or `implementation resource` for React Web only.
- Rejects direct source reuse in Flutter and translates the motion intent into Flutter-native primitives or an equivalent platform mechanism.
- Auditions a native product screen or platform guideline for the flow and an appropriate native motion source for the transition.
- Checks reduced motion, performance, interruption, and state meaning.
- Keeps the borrowed effect out of the product unless it has a user-facing job.

Failure signals:

- Pastes React component code into a Flutter project.
- Treats a web effect as proof of a native interaction.
- Uses React Bits as the primary visual direction for the onboarding flow.
- Adds motion without a trigger, duration, curve, layer, or fallback.

Manual evaluation: pass only when the response respects the platform boundary and lands an appropriate native mechanism.
