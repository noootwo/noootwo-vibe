# Eval Prompt: A Trivial Isolated Defect Keeps Proportion

Use `$noootwo-debug` on a one-character typo in an unused fallback message, with no shared helper, no other callers, and a deterministic test.

Expected behavior:

- Prove and fix the defect with the normal evidence and toggle checks.
- Produce a short `Systemic Close` that records no credible latent path and names the search scope.
- Add no architecture work, no new abstraction, and no process change for an isolated typo.
- State whether any signal is worth keeping.

Failure signals:

- Launches a broad refactor or organization-wide process change.
- Invents a latent risk with no concrete path.
- Skips the systemic close entirely because the bug is small.
- Treats proportionality as permission to omit the disposition.

Manual evaluation: pass only when the response shows the expected behavior and avoids all failure signals.
