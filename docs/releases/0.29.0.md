## What Changed

- A source is now chosen for the evidence role it can actually carry: product evidence, platform convention, visual direction, motion mechanism, implementation resource, asset source, or research craft.
- Standard UI work performs a bounded 2-3 candidate audition with one inspected primary and at most one narrow supplement. Deep work uses 3-5 sources, same-medium evidence, full capture and licence records, fit scoring, a reference lock, and 2-3 spikes.
- Product UI needs selected product evidence; galleries cannot decide flow or information architecture; component demos cannot become visual direction; native work needs native or platform-specific evidence.
- `.noootwo/appearance-ledger.md` keeps reviewed project-local accepts and rejects. It is read by matching surface and audience, never becomes global taste memory, and never creates a second state root.
- Mechanism Landing QA blocks `ready` when a selected mechanism is missing from the artifact, swallowed by a default component, or present only as decoration.
- Source and asset reuse now records access, evidence level, licence, attribution, commercial use, capture state, freshness, and fallback. The free path remains complete; paid screen libraries are optional accelerators.
