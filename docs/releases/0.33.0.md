## What Changed

- `noootwo-design` separates bounded display type from fixed product roles and requires one application-root semantic source.
- The Design Contract names display, page title, local title, body, control, label, annotation, keycap, numeric, and resize roles, including minima, caps, line height, and allowed surfaces.
- Repair starts by classifying the cause as register, token scope, blanket override, or role scale, then fixes the owning layer once instead of nudging components repeatedly.
- Artifact review measures populated rendered roles, heading viewport share, readable minima, long CJK, and 200-percent or equivalent narrow-layout evidence.
- Failure flags block display `clamp()` on operational surfaces, blanket overrides, route-only token definitions, unreadably small copy, oversized headings, settings inheriting login scale, flattened local hierarchy, and source-only review.
- The Design Intake names the write target before editing. A project supplied as a case, reference, or comparison is read-only evidence and is never patched to demonstrate a skill change.
- Harness templates now include the typography role table in token and review records.
