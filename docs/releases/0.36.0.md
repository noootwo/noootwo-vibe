## What Changed

- `noootwo-workflow 0.27.0` adds Step 0, a Mandate Gate: every request names `answer | diagnose | propose | edit | publish` before owner matching.
- A completed Fan-out Gate no longer makes a plan execution-ready. Only the user's acceptance of the presented proposal does; publication acceptance is a separate boundary.
- `references/mandate-gate.md` records the diff-summary test, fail-closed handling of unreadable intent, proposal shape, approval semantics, and cost controls.
- Open-ended grants record delegated scope and keep irreversible migration, security or privacy, spend, and publication boundaries closed.
- `noootwo-design`, `noootwo-code-health`, `noootwo-tdd`, `noootwo-debug`, and `noootwo-product` each carry one entry pointer so a direct route cannot bypass the gate.
- `noootwo-ask` explains the mandate vocabulary to the human.
- ADR 0036 records the decision, sources, boundaries, and rejected alternatives.
