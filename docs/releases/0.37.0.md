## What Changed

- `noootwo-design 0.26.0` starts review with an Observation Gate: 5-8 blind observations, up to three first-pass defects with region, state, and viewport, one must-not-change item, and an evidence handle before any score.
- A Composition Pass now checks squint-based reading order, grouping and proximity, visual weight, rhythm, density, alignment and topology, and adaptation or extremes. A clean geometry table cannot pass it.
- Missing, black, blank, stale, or wrong-region/state evidence is `needs artifact`; a source read or DOM query is not an observation.
- `ready` requires `Reviewer independence: independent reviewer`; a builder-only review is capped at `refine`. `quick` records a five-line observation card.
- `craft.md` adds the WCAG 2.2 AA delta: `320` CSS px reflow, non-text contrast, text spacing, focus not obscured, dragging alternatives, target size, consistent help, redundant entry, and accessible authentication.
- Type and target guidance is corrected: CJK line length is character-based rather than `ch`-based; the `11-12px` floor is scoped to dense metadata/body roles with CJK, contrast, and resize proof; `40px` web is a product baseline above the WCAG `24x24` minimum; `390px` is not a substitute for `320` reflow.
- The readiness validator and harness template require blind observations, first-pass defects, must-not-change, both gate results, and reviewer independence. `check_visual_gates.py` adds the `320` viewport and reports the `24px` WCAG target minimum.
- Added `composition-reading-order-miss.md`, `reflow-320-miss.md`, and `state-contrast-gap.md`; updated `quick-polish.md`.
- ADR 0037 records the observation, composition, evidence, and reviewer decision. ADR 0034 carries the type-floor and line-length amendment.
- Impeccable `skill-v4.11.0` is recorded as evidence plumbing and routing, not a new design rubric. No new public skill, dependency, reference file, or state schema was added.
