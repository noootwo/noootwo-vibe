## What Changed

- `noootwo-design 0.25.0` adds a Layout Geometry Gate for changed, user-named, and contract-declared regions.
- A single-row toolbar, tab strip, filter row, breadcrumb, or control cluster fails `ready` when its rendered top and bottom insets differ beyond tolerance.
- `check_visual_gates.py` measures named and marked regions: container box, rendered insets, inner and outer gaps, alignment anchors, sibling overlap, clipping, and verdict.
- A named region with hidden children now fails as `empty` instead of passing as a self-measurement. A genuine leaf element remains measurable.
- Geometry repair requires the same selector to be re-measured and every closed geometry row to be swept before `ready`.
- `sync_local_install.py` now verifies installed `VERSION` and `SKILL.md` after copying, and `--check` verifies the local install roots without copying.
- Install documentation distinguishes catalog reload from app restart: start a new Codex task after install or update; restart only when a new task still sees the old installed version.
