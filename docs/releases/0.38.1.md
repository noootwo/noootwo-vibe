## What Changed

- `noootwo-release 0.4.1` adds `Agent installation parity` to the Release Plan, an `install` mode, a blocking release rule, and the completion criterion.
- `sync_local_install.py --all-known` now syncs the complete public set into every detected root: `~/.agents/skills`, `~/.codex/skills`, `~/.claude/skills`, `~/.cursor/skills`, `~/.gemini/skills`, `~/.windsurf/skills`, and `~/.codeium/skills` when present.
- `--json` writes a per-root, per-skill version readback for release evidence. `--check` fails on a missing copy, stale Noootwo entry, broken skill link, or version mismatch.
- Stale pruning now recognizes broken symlinks and backs each entry up by agent root, for example `~/.codex/skill-backups/<timestamp>/claude/noootwo-docs`.
- ADR 0039 records why two roots were insufficient and why the local post-merge check is release evidence. `AGENTS.md`, the release guide, README, and an eval contract carry the rule.
- The published `0.38.0` design release record is now preserved in `docs/releases/0.38.0.md`.
