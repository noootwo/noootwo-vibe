# Reference Audition Fixture

This lightweight fixture exercises the standard reference audition:

- one primary `product evidence` source;
- one narrow `visual direction` supplement;
- one rejected visual direction;
- inspected capture copies from the existing rendered direction fixture;
- a project-local appearance ledger;
- review-time mechanism landing evidence.

It validates the deterministic contract, not the truthfulness or quality of the named sources. The captures are local rendered fixtures, not screenshots of a shipped product.
